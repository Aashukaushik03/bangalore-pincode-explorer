# Bangalore Pincode Explorer

A simple full-stack application to search Bangalore pincodes and area names.

---

## Features

- Search area names using pincode
- Search pincode using area name
- REST API support
- Responsive UI

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

---

## Installation

### Clone Repository

git clone https://github.com/yourusername/bangalore-pincode-explorer.git

### Backend Setup

cd backend

npm install

npm start

Server runs on:
http://localhost:5000

---

### Frontend Setup

Open frontend/index.html in browser

---

## API Endpoints

### Get Area by Pincode

GET /pincode/560038

### Get Pincode by Area

GET /area/indiranagar

---

## Sample Data

560038 → Indiranagar

560034 → Koramangala

560066 → Whitefield
